# Glamourly ✨

> A modern, seamless salon appointment and beauty services booking platform.

> 🚧 **Work in Progress:** Glamourly is actively under development. Features, database schemas, and UI components are continuously evolving.

---

## 📌 Overview

**Glamourly** simplifies how clients discover salons, browse treatments, and schedule appointments. Built with modern web technologies, the platform delivers an intuitive booking flow, responsive interfaces, and organized schedule management.

---

## 🚀 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, React)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) with PostCSS
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Backend / Database:** Node.js & MongoDB

---

## 🛠️ Features (Planned & In Progress)

- [x] Responsive client-facing UI design
- [ ] Salon service discovery and detailed catalog view
- [ ] Interactive appointment scheduling and slot selection
- [ ] User authentication & profile management
- [ ] Salon owner dashboard for bookings and inventory
- [ ] Automated booking notifications and confirmations
